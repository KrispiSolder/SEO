# Мастерская Север — учебный сайт с SEO-дефектами

**Назначение:** практическое занятие 2.1.6.6 «Составление приоритетного списка правок», МДК.03.02, специальность 09.02.11. Разработка содержит **намеренные ошибки**, которые студенты должны исследовать, а не автоматически исправить по советам ИИ.

## Использование

1. Откройте `index.html` в браузере для знакомства с навигацией. Для проверки HTTP-статусов запустите локальный сервер: `python -m http.server 8000` в корне папки; откройте `http://localhost:8000/`.
2. Для публикации: загрузите **содержимое этой папки** в корень репозитория GitHub; Settings → Pages → Deploy from a branch → main → /(root). Сайт станет доступен по адресу `https://<имя>.github.io/<репозиторий>/`.
3. Предоставьте студентам сайт и `diagnostic-report.json` как учебный снимок диагностики, затем рабочий лист из части 3 методических материалов. Для этапа самостоятельного анализа сначала **не используйте ИИ**.
4. Сохраните дословный ответ ИИ и предложите студентам независимо обосновать каждую рекомендацию.

## Критические ограничения платформы

- `diagnostic-report.json` содержит **моделируемый HTTP 301** с `/prices-old/` на `/prices/`. Сам проект GitHub Pages не позволяет настроить этот серверный ответ как настоящий 301; папка `/prices-old/` специально не создана. При тестировании опубликованного сайта этот путь будет возвращать 404. **Не выдавайте этот 404 за соответствие учебному снимку.** Для демонстрации 301 нужен сервер с перенаправлениями.
- При публикации по адресу `username.github.io/repository/` файл `robots.txt`, лежащий внутри репозитория, **не становится файлом `/robots.txt` для всего домена**. Это учебный пример, а не действующее ограничение индексации подпапки.
- В `sitemap.xml` и `canonical` указан **условный** домен `example.test`, как и в приложении А. Это намеренная имитация входных данных; данные не описывают реальные страницы GitHub Pages.
- Показатель **4,2 секунды** — цифра из учебного кейса, не результат измерения опубликованного проекта. Текущий объём изображения см. в `diagnostic-report.json`, он может не совпадать с указанными в кейсе 3,8 МБ.
- `noindex` на странице услуг реальный и виден в HTML; битая ссылка ведёт на несуществующую страницу, канонический адрес карточки некорректен. `404.html` стилизует сообщение об ошибке на GitHub Pages.

## Безопасность

Здесь нет настоящих данных клиентов. `private/` — демонстрационный раздел: `robots.txt` не защищает сведения от неавторизованного доступа.
